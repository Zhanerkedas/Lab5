Python 3.12+, только стандартная библиотека.

## Файлы

| Файл | Назначение |
|---|---|
| `netcalc.py` | калькулятор подсетей (адрес сети, broadcast, wildcard, двоичная маска, тип адреса), разбор двух форматов адреса, VLSM с запасом роста, проверка плана, агрегация; интерактивное меню |
| `audit.py` | аудит IP-адресов устройств из `devices.csv` по плану `plan_v10.csv` (коды E1–E7, W1), отчёт в `audit_report.csv` |
| `netdiag.py` | пошаговая диагностика «снизу вверх»: стек TCP/IP → интерфейс → шлюз (определяется автоматически на Windows/Linux/macOS) → 8.8.8.8 → DNS → HTTPS; журнал `diag_log.csv` |
| `services.py` | проверка TCP-сервисов (OPEN / REFUSED / TIMEOUT / DNS-ERROR), последовательно и параллельно (`ThreadPoolExecutor`) |
| `netkit.py` | единая утилита командной строки: `calc`, `vlsm`, `audit`, `diag`, `services` |
| `plan_v10.csv` | план адресации варианта 10 (создаётся программой) |
| `devices.csv` | 17 устройств, 9 заложенных ошибок и 1 предупреждение |
| `tests/test_netcalc.py` | 19 модульных тестов |

## Примеры команд

```bash
python netkit.py -h
python netkit.py calc 10.5.5.70/26
python netkit.py calc "10.5.5.70 255.255.255.192"
python netkit.py vlsm 10.5.5.0/24 "Банк. зал=30" "Кредитный отдел=25" "Охрана=10" "Серверы=5" --growth 30 --csv plan_v10.csv
python netkit.py audit plan_v10.csv devices.csv --report audit_report.csv
python netkit.py diag
python netkit.py diag --gateway 192.168.1.1
python -m http.server 8100 --bind 127.0.0.1     # в отдельном терминале
python netkit.py services --parallel --workers 10 --timeout 3
```

Код завершения: `0` — всё в порядке, `1` — найдены проблемы (`echo %errorlevel%` в Windows, `echo $?` в Linux/macOS). Интерактивное меню: `python netcalc.py`.
